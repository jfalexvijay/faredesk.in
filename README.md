# FareDesk Website

Official website pages for **FareDesk**, a simple invoice generator designed to help small businesses create, manage, and share PDF invoices using iPhone and iPad.

This repository contains the informational and support pages for the FareDesk application. The website is hosted using GitHub Pages.

## About FareDesk

FareDesk is an invoice-generation application developed by J. Alex Antony Vijay to support small businesses with their invoicing needs.

### Key Features

- Create and manage invoices.
- Save and update draft invoices.
- Track invoice payment status.
- Generate and share PDF invoices.
- Manage business information, including GST and PAN details.
- Access core invoicing features offline.

## Deployment

The website is deployed from the `main` branch using GitHub Pages.

To update the website:

1. Edit the relevant HTML file.
2. Commit and push the changes to the `main` branch.
3. Wait for GitHub Pages to complete deployment.
4. Verify the published page.

### GitHub Pages Configuration

- **Source:** Deploy from a branch
- **Branch:** `main`
- **Folder:** `/(root)`
